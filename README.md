# 냥코대전쟁 — CHAPTER 1 : 퓨어월드

냥코대전쟁 스타일의 **진영 방어 / 병사 소환 배틀** 웹 게임에
**스토리 캠페인(액트 8개 + 보스 5전)** 이 추가됐습니다.
별도 빌드 없이 브라우저에서 바로 플레이할 수 있습니다.

## 플레이 방법

```bash
python -m http.server 8000     # 또는 npx serve .
```

브라우저에서 `index.html`을 열고 **캠페인 맵에서 액트를 선택**합니다.

## 챕터 1 — 퓨어월드

퓨어월드에 처음 발생한 균열과 원소 세력의 침공을 막는다.
최종적으로 **원소포식자 아르카논**을 격파하고 퓨어월드를 지킨다.

| 액트 | 제목 | 목표 |
|---|---|---|
| ACT 1 | 첫 균열 | 80초 방어 |
| ACT 2 | 대지의 군세 | 주민 구출 + 균열 파괴 |
| BOSS 1 | 대지룡 기간토스 | 지진·바위벽·대지 영역 |
| ACT 3 | 두 번째 침공 | 수로 균열 파괴 (침수) |
| ACT 4 | 아쿠아 | 침수 마을 주민 6명 대피 |
| BOSS 2 | 물의 정령 아쿠아 | 수위 상승·정령 소환·회복 |
| ACT 5 | 이그니스 | 90초 방어 + 주민 탈출 (화염) |
| BOSS 3 | 염제 이그니스 | 화염 지대·체력 비례 사거리 |
| ACT 6 | 번개의 침공 | 후방 기습 균열 거점 파괴 |
| BOSS 4 | 번개의 볼트라스 | 순간이동·고속 돌진·연쇄 번개 |
| ACT 7 | 원소포식자 아르카논 | WORLD BOSS 4원소 페이즈 교체 |
| ACT 8 | 끝나지 않은 균열 | 엔딩 컷신 |

### 조작

| 키 | 동작 |
|---|---|
| `1`~`7` | 병사 소환 |
| `Q` | 엑스칼리버 (아서왕 있을 때) |
| `W` | 대운석 낙하 (멀린 있을 때) |
| `U` | 워커 강화 (수입 증가) |
| `스페이스` | 일시정지 / 재개 · 컷신 다음 문장 |
| `F` | 게임 속도 ×1 / ×2 |
| `🎵 BGM` / `🔊 효과음` | 사운드 온·오프 (설정 저장) |

### 유닛 특수 능력

- **성기사** — 주변 아군이 받는 피해 -40% (오러)
- **백마기사** — 돌진 공격 시 적 넉백
- **그림자 암살자** — 30% 확률 치명타 5배
- **대마법사 멀린** — 기본공격에 별 강하(광역+화상)
- **아서왕** — 기본공격 **신의 손** 소환(광역+스턴)

### 진행 저장

클리어한 액트는 `localStorage`에 저장되어 캠페인 맵에서 유지됩니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | UI 구조 (HP/보스바/컷신/스킬/맵) |
| `style.css` | 다크 테마 + 컷신 스타일 |
| `data.js` | 콘텐츠 데이터 (스토리·유닛·보스·액트) |
| `game.js` | 엔진 (전투 AI·보스 메커니즘·렌더링) |
| `audio.js` | 사운드 (Web Audio 합성 BGM 4트랙 + 효과음 24종) |
| `assets/` | 이미지 에셋 (없으면 이모지 대체) |

이미지 넣는 법은 [assets/README.md](assets/README.md) 참고.

## 기술 스택

순수 HTML / CSS / JavaScript (캔버스 2D), 외부 의존성 없음.
오디오 파일도 없음 — BGM/효과음은 전부 Web Audio API로 실시간 합성합니다.
(브라우저 정책상 첫 클릭 후 소리가 시작됩니다)
