# 냥코대전쟁 — 가챠 · 캐릭터 편성 · 3챕터

냥코대전쟁 스타일의 **진영 방어 / 병사 소환 배틀** 웹 게임에
**가챠(뽑기) · 캐릭터 편성 · 레벨업 · 3개 챕터 캠페인(총 26 액트)** 이 추가됐습니다.
별도 빌드 없이 브라우저에서 바로 플레이할 수 있습니다.

## 플레이 방법

```bash
python -m http.server 8000     # 또는 npx serve .
```

브라우저에서 `index.html`을 열고 **캠페인 맵에서 액트를 선택**합니다.

## 신규 시스템

### 🎰 가챠 (뽑기)
- 재화: **🍗 냥코푸드** — 액트 클리어 보상으로 획득 (첫 클리어 보너스 포함)
- **1회 뽑기 150 / 10연차 1500** (10연차 마지막은 SR 이상 확정)
- 등급: `R 70% · SR 24% · SSR 6%`
- 가챠 한정 영웅 8종: 광전사 · 왕국 명사수 · 그림자 닌자 · 음유시인 · 발키리 · 불사조 · 공허의 인도자 · 전설의 냥코
- **중복 획득 시 ★ 돌파** (+5% 스탯, 최대 5성) · 최종성 중복은 ✨XP 200 환급

### 📋 캐릭터 편성
- **챕터별 최대 10명** 편성 (단축키 `1`~`9`, `0`으로 소환)
- 맵의 [캐릭터 편성] 버튼에서 편성 변경 · 보유 영웅 전체 로스터 표시

### ⬆️ 레벨업
- 재화: **✨ 경험치** — 액트 클리어 보상
- 유닛당 **Lv 1 ~ 30** (`강화` 버튼, 비용은 레벨별 증가)
- 스탯 배율: `1 + 4%·(Lv-1)` × `1 + 5%·★` (Lv30 = 2.16배)
- 밸런스 진행: 챕터1 BOSS 3은 **Lv3 이상**에서 돌파 가능

## 조작

| 키 | 동작 |
|---|---|
| `1`~`9`, `0` | 병사 소환 (편성 순서 1~10번) |
| `Q` | 엑스칼리버 (아서왕 있을 때) |
| `W` | 대운석 낙하 (멀린 있을 때) |
| `U` | 워커 강화 (수입 증가) |
| `스페이스` | 일시정지 / 재개 · 컷신 다음 문장 |
| `F` | 게임 속도 ×1 / ×2 |
| `ESC` | 전투→맵 · 가챠/편성→맵 · 맵→타이틀 |
| `🎵 BGM` / `🔊 효과음` | 사운드 온·오프 (설정 저장) |

## 유닛 특수 능력 (총 20종)

### 기본 12종
- **성기사** — 주변 아군이 받는 피해 -40% (오러)
- **백마기사** — 돌진 공격 시 적 넉백
- **그림자 암살자** — 30% 확률 치명타 5배
- **화염용기사** — 전방 250px 부채꼴 화염 + 화상
- **대마법사 멀린** — 기본공격에 별 강하(광역+화상)
- **서리검사** — 피격 적 2.5초 둔화 + 15% 스턴
- **성녀** — 성빛 공격 + 가장 아픈 아군 치유
- **폭풍검사** — 주변 적 2명에게 연쇄 번개
- **황금 거수** — 지진 충격파(광역 넉백+스턴)
- **아서왕** — 기본공격 **신의 손** 소환(광역+스턴)

### 가챠 한정 8종
- **광전사 (R)** — 체력 35% 이하에서 공격력 2.2배
- **왕국 명사수 (R)** — 사거리 480 초장거리 저격 + 넉백
- **그림자 닌자 (R)** — 45% 확률 치명타 6배 · 속도 145
- **음유시인 (SR)** — 주변 아군 공격력 +35% (오러)
- **발키리 (SR)** — 번개 연쇄 3명
- **불사조 (SR)** — 화염 숨결 + **전투 중 1회 부활**
- **공허의 인도자 (SSR)** — 7주기 광역 공허 폭발 + 둔화
- **전설의 냥코 (SSR)** — 광역 넉백 + 스턴의 강타
